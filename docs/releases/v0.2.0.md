Sotto 0.2.0: a private, end-to-end encrypted workspace for teams.

- **Groups and channels.** End-to-end encrypted group chats with admins, pinned messages, files and a safety number everyone can compare. Channels for one-way updates where followers never see each other, with private replies and opt-in read receipts.
- **Calls.** Voice calls and group calls through your organization's call server, end-to-end encrypted.
- **Tags.** Claim a tag like @ada so people can reach you without a link, on your relay or any other (ada@relay.example.org). You accept each new contact first.
- **Avatars.** Everyone gets a unique avatar, and you can pick from 960 in the collection.
- **For developers.** Code blocks with highlighting, integrations that post from scripts and CI (with the sotto-hook command), and one-time secrets.
- **Search** inside any conversation, group or channel (Ctrl+F).
- **Signed updates.** From this version on, Sotto updates itself. Every release is signed with the Sotto release key, and the app checks the signature and every file's fingerprint before installing.
