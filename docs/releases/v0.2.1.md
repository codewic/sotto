Sotto 0.2.1: a message box worth typing in.

- **Formatting without remembering the marks.** Select text for a small toolbar (bold, italic, code, code block, quote), or use Ctrl+B, Ctrl+I, Ctrl+E and Ctrl+Shift+C. Messages are still plain text with light markup.
- **Several files at once.** Attach, paste or drop up to 10 files. They wait in a tray with thumbnails and sizes, with one caption for the set. If one fails partway, only the files that didn't go stay behind, so nothing is sent twice.
- **Mentions in groups.** Type @ to pick a member. Mentions stand out in the conversation, and the person you mention gets an @ on the group in their list, even if they've muted it.
- **Emoji.** A picker with search, and :shortcode: completion as you type.
- **Commands.** Type / for /code, /later, /emoji, /secret and /call.
- **Send later.** Pick a time, from a minute to 30 days ahead. The message is held encrypted on your computer and goes when it's due, while Sotto is open and unlocked. Cancel it any time from the chip above the message box.
- **Drafts everywhere.** Groups and channels keep unsent text too, and the list shows "Draft:" in the preview. Drafts stay in memory only, so they're gone once Sotto locks.
- **Fixed:** Ctrl+I in the message box now makes text italic instead of opening the info panel, and renaming yourself no longer loses track of which group member is you.
